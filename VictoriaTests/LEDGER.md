Every test file, the invariant it protects, and the release that introduced it. Changing a behaviour means changing its test in the same change and noting why here.

**Totals (as of 2026-11-22, recounted from the files): 491 test methods in 34 test files** (all XCTest, one `XCTestCase` subclass per file; plus 1 support file, `Support/ScriptedTransport.swift`, which has no tests and is the table's last row).

Counted as `func test…()` declarations per file (`grep -c 'func test' <file>`, re-run for every row on 2026-11-22), cross-checked with a strict pattern (`^\s*func test\w*\(\) (async )?(throws )?\{`) that matched the same 490 — there are no parameterised/private helpers named `test…`, no `XCTSkip`, and no Swift Testing (`@Test` / `import Testing`: zero hits). The count is static (source), not from a test run. The CI gate (`.github/workflows/ci.yml`, `check_xcresult.py --min-tests 491`) uses the same number; raise both together.
